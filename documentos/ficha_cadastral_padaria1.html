ℹ️ O Que é o "Prefixo do Usuário" no Aion ERP? (Explicação do Sistema)

O Aion ERP possui arquitetura Multicliente (Multi-tenant) com bancos de dados isolados no PostgreSQL (Neon). Como a tela de login (index.html) é única para todas as empresas, o PREFIXO DO USUÁRIO é a chave exclusiva que identifica a loja.
• Regra de Login: Todos os logins seguem o formato <usuario>.<prefixo> (ex: adm.padaria1, caixa.padaria1, balcao.padaria1).
• Validação no Sistema: Ao digitar o login, o sistema detecta o sufixo .padaria1, busca as credenciais no arquivo clients.json e conecta automaticamente ao banco de dados isolado da Padaria 1 antes de validar a senha.
